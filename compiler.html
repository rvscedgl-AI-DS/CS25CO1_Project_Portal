Your browser-based C programming workspace

Write a C program, provide input before execution, compile it, and inspect program output or compiler diagnostics. The embedded compiler uses WebAssembly in the browser; your source code is not sent to a remote compilation server by this compiler engine.

First visit: The compiler toolchain is approximately 23 MB compressed and may take a little time to load. The browser can cache it for later visits. An internet connection is needed for the initial download.

How to provide input to your C program

  1. Write your program using functions such as scanf() to read values.
  2. Locate the compiler's Input (stdin) box.
  3. Enter values before running. For scanf("%d %d", &a, &b), you can enter 10 20.
  4. For multiple inputs, separate values with spaces or put them on separate lines, as your program expects.
  5. Press Compile/Run and check the Console for output or errors.

Important notes for students

  • This first version is intended for introductory, single-file C programs.
  • The compiler engine uses Clang/WebAssembly, not the GCC compiler installed in the college lab.
  • Programs depending on operating-system-specific features, external libraries, networking, or multiple source files may not work in this version.
  • Save a copy of your source code regularly. Do not treat the browser editor as your only storage location.
