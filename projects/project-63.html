PROJECT 63 OF 65

Digital Banking Application

Unit / Topic: Integrated Projects – Multiple Concepts

Project Description

Support balance enquiry, deposits, withdrawals and transaction counting using functions and pointers.

Learning Outcomes

After completing this project, the student will be able to:

  • Break the problem into smaller tasks and design a clear function for each task.
  • Organise related functions into modules and use a suitable user-defined header file where appropriate.
  • Compile and test the program from multiple source files and explain the role of each module.

Implementation Guidelines

  • Use meaningful function names and declare functions before they are called.
  • Validate user inputs where appropriate and display clearly labelled results.
  • Include comments for important logic and keep the program readable.
  • Separate the program into logically related .c source files.
  • Create and include a user-defined .h file containing suitable declarations.
  • Provide the compile command used to build all source files.

Submission Guidelines

  • Submit the complete C source code file(s).
  • Include the problem statement, algorithm or step-by-step logic, and a flowchart where appropriate.
  • Provide at least three test cases with input and expected or actual output.
  • Attach screenshots or a record of successful program execution, as instructed by the course faculty.
  • Be prepared to explain the function declaration, definition, function calls, parameters and return types used in your program.
  • Attend an individual demonstration and viva. You may be asked to modify a function or test a new input during the assessment.
Academic integrity: Understand every line of your implementation. External tools may be used only as permitted by the course faculty; you must be able to explain and independently modify your code.
