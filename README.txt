R.V.S. College of Engineering, Dindigul
Department of Artificial Intelligence and Data Science

HOW TO USE
1. Open index.html in a web browser to view the project list.
2. Select any project number/title to open its individual project page.
3. Keep the index.html file and the projects folder together.
4. To publish the website, upload the complete folder contents to your web hosting service.

This is a static website. It has no faculty allocation, login, database, or dynamic student data.
The search filter runs locally in the browser.

ONLINE C PROGRAMMING LAB
------------------------
Open compiler.html from the project portal. It embeds the Derle browser-based
C compiler and provides a new-tab fallback. The compiler engine uses Clang/LLD
and runs compiled programs using WebAssembly in the browser. The first visit
downloads the toolchain (approximately 23 MB compressed), which the browser
may cache.

Compiler engine: https://github.com/senolgulgonul/derle
Review the upstream licence and notices before modifying, redistributing, or
self-hosting its compiler files. This portal integration does not claim
authorship of the compiler engine.

If your hosting provider blocks iframe embedding, use the Open compiler in a
new tab link on compiler.html. A fully self-hosted deployment requires
obtaining and reviewing the upstream source, toolchain assets, licence notices,
and hosting requirements.
